## 👋 Sobre mim

Meu nome é **Eduardo Múcio**.

Sou desenvolvedor **FullStack**, com foco na criação de aplicações web, interfaces modernas e sistemas que unem uma boa experiência no frontend com uma estrutura funcional no backend.

Gosto de transformar ideias em projetos reais, experimentar novas tecnologias e evoluir constantemente através da prática.

Atualmente, minhas principais tecnologias estão concentradas no ecossistema **JavaScript**, trabalhando tanto no desenvolvimento de interfaces quanto na construção de APIs e aplicações backend.
